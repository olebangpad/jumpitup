# 점프잇업 (Jump It Up)

물이 차오르기 전에 잎사귀를 밟고 끝까지 올라가는 세로 등반 게임입니다.
캐릭터마다 움직이는 방식이 달라요.

`index.html` 파일 하나로 돌아갑니다. 설치할 것 없이 브라우저로 열면 바로 할 수 있어요 (PC, 휴대폰 모두 됨).

## 하는 방법

- 위·아래·왼쪽·오른쪽으로 한 칸씩 움직여서 잎사귀를 따라 올라가요.
- **빈칸**을 밟으면 떨어져요.
- **금 간 잎(갈색)** 은 밟고 0.75초가 지나면 부서져요. 멈추지 말고 지나가세요.
- 아래에서 **물**이 계속 차올라요. 시간이 지날수록 빨라져요.
- 아이템
  - 🪰 파리: 점수 +5
  - 💧 이슬: 능력 바로 충전 (달팽이는 점액 +1, 바퀴벌레는 목숨 +1)
  - ❄️ 얼음꽃: 물이 4초 동안 멈춤
- 점수 = 높이(m) + 파리 × 5. 캐릭터별 최고 기록이 저장돼요.

## 캐릭터

| 캐릭터 | 속도 | 능력 | 특성 |
|---|---|---|---|
| 개구리 | ●●●○○ | **멀리뛰기**: 능력을 켜고 방향을 고르면 2칸 점프 (구멍도 넘어감) | 물이 15% 느리게 차오름 |
| 바퀴벌레 | ●●●●● | 없음 | 목숨 3개. 떨어지거나 빠져도 마지막 잎에서 다시 일어남 |
| 메뚜기 | ●●●●○ | **슈퍼점프**: 위로 최대 4칸 날아올라 가장 높은 잎에 착지 | 위로 갈 때 더 빠름 |
| 달팽이 | ●○○○○ | **점액 다리**: 능력을 켜고 빈칸 쪽으로 가면 발판을 만듦 (충전식, 20m마다 +1) | 금 간 잎도 부서지지 않음 |
| 무당벌레 | ●●●○○ | **날개짓**: 1.8초 동안 날아서 빈칸 위를 지나가고 물도 피함 | 나는 동안 금 간 잎을 건드리지 않음 |

## 조작

| | 키보드 | 휴대폰 |
|---|---|---|
| 이동 | 방향키 또는 WASD | 아래 화살표 버튼, 또는 화면을 밀기 |
| 능력 | Space (Shift, J, K도 됨) | 노란 동그라미 버튼 |
| 일시정지 | P 또는 Esc | 오른쪽 위 버튼 |
| 캐릭터 고르기 | ← → 후 Enter | 터치 |

## 실행하기

- 그냥 `index.html`을 더블클릭해서 브라우저로 열면 됩니다.
- 휴대폰에서 하려면 GitHub Pages를 켜면 돼요: 저장소 **Settings → Pages → Branch** 에서 브랜치를 고르고 저장하면 `https://<아이디>.github.io/jumpitup/` 주소가 생겨요.

## 구조

모든 코드가 `index.html` 안에 있어요.

- `CHARS`: 캐릭터 목록 (이름, 속도, 능력, 특성). 새 캐릭터를 넣으려면 여기에 추가하고 `CHAR_DRAW`에 그림 함수를, `useAbility()`에 능력 동작을 넣으면 돼요.
- `World`: 맵 생성. 4방향 이동만으로 항상 올라갈 수 있는 길을 먼저 만들고, 그 주변에 곁가지·막다른 길·외딴 잎을 뿌려요. 금 간 잎은 막다른 길 옆에는 생기지 않아서 갇히는 일이 없어요.
- `update()` / `render()`: 게임 루프. 그림은 전부 캔버스에 코드로 그려서 이미지 파일이 없어요.
